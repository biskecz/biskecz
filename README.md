A modular backtesting framework for evaluating moving-average crossover strategies.

* Transaction costs
* Total Return
* CAGR
* Sharpe Ratio
* Maximum Drawdown
* Win Rate
* Profit Factor
* Trade statistics
* Strategy vs Buy & Hold

* Look-ahead bias prevention
